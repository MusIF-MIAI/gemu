333 * SA bit 0 cleared by CU10 = DI64A0); SA bit 0 IS the flow chart's <SA00>

335 * tables CPU[7] p64 ("FASE ALFA ED-EC / EF-EE", dwg 14024137₀, fo.15-16):
336 *
337 * ED|EC — CO18 + CO97..CO90 force the NO knot to the change-register LOW
338 * byte address 1111 nnn 1 = 241+2N (N = modifier, L2 bits 4-6 via
339 * the {L206}/{L205}/{L204} gates; CO90's DI65A0 gate sets the odd
340 * byte only in this state); MEM->RO reads it; V2->NO / NO->BO put
341 * the displacement on the UA's other input; CO49 resets the carry
342 * FFs; CI69 latches UA = BO.low + RO into NI21; CI02 stores NI
343 * (V2 high byte unchanged through the counting network) to V2;
344 * CU01 -> EF|EE.
345 * EF|EE — same address build WITHOUT CO90 (= 240+2N, the HIGH byte);
346 * CI68 latches UA = BO.high + RO + carry into NI43; CI02 stores
347 * the resolved EA to V2; CI01 (DI67A0 {SA00}) copies it to V1 for
348 * the first operand. Routing: CU01/CU11 (net Reset S001) + CU13
349 * always; CU17 = DE52A0 {/FO07+/FO06+/SA00} exits to beta except

401/* Interruption + LPSR chain, per-clock (cp07 timing charts fo.22-31, dwg
402 * 14024137, read from source at 600dpi):
403 *
404 * E2/E3 --INTE--> F0 -> D2 -> D3 -> D0 -> D1 -> C2 -> C3 -> C0 -> C1 -> E2/E3
405 * LPSR (beta 64|65, fo.27) ------------------------^ (C2 header: "DA-FROM 64+65 D1")
406 *
407 * F0 forces 0x0300 into V1 (CI19 + C091/C090 -> NO43, latched into BO at the
408 * TO50 relatch, stored by CI01). The D-states WRITE the old PSR at V1++:
409 * D2 = status byte from the FA-gated forcings via NO43 (FA06->b0, FA05->b4,
410 * FA04->b5), D3 = zero (its forcing rows have no mode command, and the NO
411 * selection pulse has decayed by TO50 -> NO_UNDRIVEN), D0/D1 = PO high/low
412 * (CI10 PO->NO at TO30, CI32/CI33 at TO50). The C-states READ the new PSR at
413 * V1++ (0x0304 onward for the interrupt path; the LPSR operand address for
414 * LPSR): C2 = status byte -> FI04/05/06 (set, then conditional reset on the
415 * R0 bits — reset listed after set, as the hardware resolves it), C3 = skip
416 * byte, C0/C1 = PO high/low assembled through NI (RO halves + the BO
417 * passthrough of the counting network, CI00s at TI05).
418 *
419 * TI06 CU rows are ordered sets-before-resets so gemu's sequential dispatch
420 * preserves the hardware "reset prevails" rule; the printed row order on the
421 * sheets is data-equivalent. All exits are unconditional per the sheets. */

766/* Beta phase instruction sheets.
767 *
768 * CPU[7] prints multiple 64|65 timing sheets, selected by the instruction
769 * decode matrix. They are one MSL, not several: the sheets differ only where
770 * a row carries a family term, and every sheet reprints the rows that do not.
771 * Those go in beta_64_common below and run for every instruction entering the
772 * state; each array that follows carries only what the decode multiplexes, so
773 * it reads as the DELTA against the physical sheet rather than the whole page.
774 *
775 * Some rows remain to be transcribed; the EXEC rows are temporary markers
776 * pending the downstream datapath commands described below and in
777 * docs/flowchart-sheets.md. */
778
779/* Rows every 64|65|66 sheet prints, with no family term on any of them: the
780 * beta phase always clears the two future-state bits that route it out of
781 * 0110 01XX. CU10 (reset S000) retires the X bit -- beta is entered as 64 or
782 * 65 depending on the alpha exit, and neither successor keeps bit 0 -- and
783 * CU12 (reset S002) drops the 0x04 that distinguishes beta from the executive
784 * and alpha bands. Whichever CU0x SETS follow from the variant then name the
785 * successor: +CU01+CU07 -> E2 (return to alpha), +CU03 -> EA (link/register
786 * write), +CU15+CU03 -> CC (external), none -> 60|62 (executive loop).
787 *
788 * Safe to hoist ahead of the variant rows: no 64|65 sheet issues CU00 or CU02,
789 * so no variant row contends with these two bits. */
790/* Every function class the beta sheets cover. Used only by the compatibility
791 * guard below -- with the dispatch table gone there is no "last variant", so
792 * "no sheet claimed this code" has to be said explicitly. */

794 return beta_jump_control(ge) || is_jrt(ge) || is_la(ge) || is_lpsr(ge) ||
795 beta_register(ge) || beta_immediate_shift(ge) || per_peri(ge) ||
796 ss_byte_loop(ge) || is_ss_data_op(ge);
797}
