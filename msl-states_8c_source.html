351/* Entered from E6 (operand 1 -> ED, SA bit 0 set) or E7 (operand 2 -> EC,
352 * SA bit 0 cleared by CU10 = DI64A0); SA bit 0 IS the flow chart's <SA00>

354 * tables CPU[7] p64 ("FASE ALFA ED-EC / EF-EE", dwg 14024137₀, fo.15-16):
355 *
356 * ED|EC — CO18 + CO97..CO90 force the NO knot to the change-register LOW
357 * byte address 1111 nnn 1 = 241+2N (N = modifier, L2 bits 4-6 via
358 * the {L206}/{L205}/{L204} gates; CO90's DI65A0 gate sets the odd
359 * byte only in this state); MEM->RO reads it; V2->NO / NO->BO put
360 * the displacement on the UA's other input; CO49 resets the carry
361 * FFs; CI69 latches UA = BO.low + RO into NI21; CI02 stores NI
362 * (V2 high byte unchanged through the counting network) to V2;
363 * CU01 -> EF|EE.
364 * EF|EE — same address build WITHOUT CO90 (= 240+2N, the HIGH byte);
365 * CI68 latches UA = BO.high + RO + carry into NI43; CI02 stores
366 * the resolved EA to V2; CI01 (DI67A0 {SA00}) copies it to V1 for
367 * the first operand. Routing: CU01/CU11 (net Reset S001) + CU13
368 * always; CU17 = DE52A0 {/FO07+/FO06+/SA00} exits to beta except
369 * for the first operand of a two-address op, which goes to E5 to
370 * fetch operand 2. Exit box: 64+65 {/(SA00·FO07·FO06)} |

420/* Interruption + LPSR chain, per-clock (cp07 timing charts fo.22-31, dwg
421 * 14024137, read from source at 600dpi):
422 *
423 * E2/E3 --INTE--> F0 -> D2 -> D3 -> D0 -> D1 -> C2 -> C3 -> C0 -> C1 -> E2/E3
424 * LPSR (beta 64|65, fo.27) ------------------------^ (C2 header: "DA-FROM 64+65 D1")
425 *
426 * F0 forces 0x0300 into V1 (CI19 + C091/C090 -> NO43, latched into BO at the
427 * TO50 relatch, stored by CI01). The D-states WRITE the old PSR at V1++:
428 * D2 = status byte from the FA-gated forcings via NO43 (FA06->b0, FA05->b4,
429 * FA04->b5), D3 = zero (its forcing rows have no mode command, and the NO
430 * selection pulse has decayed by TO50 -> NO_UNDRIVEN), D0/D1 = PO high/low
431 * (CI10 PO->NO at TO30, CI32/CI33 at TO50). The C-states READ the new PSR at
432 * V1++ (0x0304 onward for the interrupt path; the LPSR operand address for
433 * LPSR): C2 = status byte -> FI04/05/06 (set, then conditional reset on the
434 * R0 bits — reset listed after set, as the hardware resolves it), C3 = skip
435 * byte, C0/C1 = PO high/low assembled through NI (RO halves + the BO
436 * passthrough of the counting network, CI00s at TI05).
437 *
438 * TI06 CU rows are ordered sets-before-resets so gemu's sequential dispatch
439 * preserves the hardware "reset prevails" rule; the printed row order on the
440 * sheets is data-equivalent. All exits are unconditional per the sheets. */
441
