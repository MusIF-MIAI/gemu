Detailed Description

One instruction-family variant of a sequencer state.

The GE-120 manual prints several timing charts for the same numerical state (notably 64|65 and the executive-state pairs), selected by the instruction decode matrix. Keeping each sheet in a separate chart makes the transcribed rows directly comparable with the corresponding manual page.

A variant now holds only the rows that CARRY A FAMILY TERM. Rows the sheets print identically for every family live in the state's common chart – see msl_timing_state::chart.
