Rows the decode multiplexes for the instruction currently in FO.

NULL when the state has no variant matrix, or – the tripwire – when it has one and nothing matched, which means a family reached an executive state whose sheet has not been transcribed yet. The state's common rows still run in that case: they carry no family term, so the real MSL would perform them regardless of what the decode matrix says.
